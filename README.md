# Continuous Current Date Time

A focused React frontend that continuously displays the visitor's current date, time, and browser time zone in a clear responsive interface.

![Continuous Current Date Time screenshot](screenshot.png)

## Features

- Live date and time updates every second
- Browser locale formatting and resolved time zone
- Fixed scroll-aware header with a small-screen menu
- Accessible semantic time element, focus states, and back-to-top control
- Local favicon, logo, social preview, and feature image assets

## Tech Stack

- React 18
- Vite
- Plain CSS
- React Icons

## Setup

\`\`\`bash
npm install
npm start
\`\`\`

Open the local URL shown by Vite. Run the linter and create a production build with:

\`\`\`bash
npm run build
\`\`\`

To publish the `dist` build to the GitHub Pages branch, run `npm run deploy`.
